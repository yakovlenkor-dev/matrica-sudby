МАТРИЦА СУДЬБЫ — Android-проект

Что это:
- Android-приложение с названием «Матрица судьбы» и собственной иконкой.
- Текущая версия HTML-программы встроена внутрь приложения и открывается офлайн.
- При сборке устанавливается как обычное приложение и появляется в меню приложений/на главном экране.
- Основные данные программы сохраняются в локальном хранилище WebView на устройстве.

ВАЖНО:
Это исходный проект Android Studio, не готовый APK. В этой среде Android SDK/сборщик APK недоступен, поэтому APK здесь не был собран. Не устанавливай случайные APK из неизвестных источников.

Как собрать APK на компьютере:
1. Установи Android Studio с официального сайта developer.android.com/studio.
2. Распакуй архив.
3. В Android Studio выбери Open и укажи папку MatricaSudbyAndroid.
4. Дождись синхронизации Gradle и установки Android SDK Platform 35, если Android Studio попросит.
5. Выбери Build → Build Bundle(s) / APK(s) → Build APK(s).
6. Нажми Locate в уведомлении Build APK(s). Полученный app-debug.apk перенеси на телефон и открой его для установки.
7. Если Android спросит, разреши установку для приложения, которым открываешь APK. Устанавливай только собственную сборку.

Можно также подключить телефон кабелем USB и нажать Run в Android Studio.

Технические сведения:
- package/applicationId: ru.matricasudby.app
- minSdk: Android 7.0 (API 24)
- version: 1.0.0
- интернет-разрешение не запрашивается; приложение рассчитано на офлайн-работу.

Примечание: это упаковка текущей HTML-версии в Android WebView, а не переписанная с нуля нативная программа. Функции HTML-версии сохранены настолько, насколько их поддерживает Android WebView.


ДОПОЛНИТЕЛЬНО: автоматическая облачная сборка через GitHub Actions
В папке .github/workflows лежит сценарий build-apk.yml. После загрузки всего проекта в репозиторий GitHub с включёнными Actions, он автоматически попробует собрать APK и приложить его как Artifact к запуску workflow. Это не означает, что APK уже создан: для запуска облачной сборки нужен репозиторий GitHub и загрузка исходников в него. В данном чате нет доступного репозитория пользователя, поэтому я не могу запустить эту сборку от его имени.
